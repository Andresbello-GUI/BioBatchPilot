# BioBatchPilot
Personal Coding Space (PROJECT:0, V:1.0)
### Bioprocess Decision Simulator

> Practice biomanufacturing decisions before you make them in a real GMP environment.

BatchPilot is an interactive training simulator for biomanufacturing. Users enter realistic bioprocess scenarios, interpret process data, make decisions, and receive immediate expert technical feedback — with consequences.

Not a course. Not a quiz. A decision simulator.

---

## What it does

Each scenario places you inside a real bioprocess situation:
- Review live process data (VCD, viability, glucose, lactate, pH, DO, titer)
- Choose an action from realistic options
- See the consequences of your decision
- Receive technical feedback explaining what an experienced scientist would do

---

## Tech stack

- Python
- Streamlit
- Plotly
- Pandas

---

## Run locally

```bash
pip install streamlit plotly pandas numpy
streamlit run main.py
```
